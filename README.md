# xyron.io

The website for Xyron Ltd, served by GitHub Pages from the `main` branch at [xyron.io](https://xyron.io).

The site is plain HTML and CSS. It has no build step of its own, runs no scripts, sets no cookies and loads nothing from other websites.

## Files

| Path | What it is |
|---|---|
| `index.html` | The homepage |
| `pandp.html` | Privacy and cookie policy |
| `404.html` | Shown for an address that does not exist |
| `assets/css/site.css` | All styling. Brand colours and fonts are set as variables at the top |
| `assets/fonts/` | Hanken Grotesk and Atkinson Hyperlegible, with their SIL Open Font Licences |
| `assets/img/` | The logo and the image shown when a link to the site is shared |
| `favicon.ico`, `favicon.svg`, `apple-touch-icon.png` | Browser and phone icons |
| `images/`, `img/` | The previous logo files, kept in case anything still links to them |
| `CNAME` | Connects the repository to xyron.io. Do not delete it |

## Making changes

Edit the HTML or CSS, commit, and push to `main`. GitHub Pages republishes the site within a few minutes.

To preview locally, open `index.html` in a browser.

## Brand

The site uses the Xyron "Vantage" identity: pine `#0F3B2E`, fern `#1E6B4F`, lichen `#C8DA5E`, mist `#E4EEE8` and ink `#14201B`, with Hanken Grotesk Bold for headings and Atkinson Hyperlegible for text. The lichen accent is used on pine only.
